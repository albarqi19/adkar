# قلب يذكر الله – تطبيق استغفار وأذكار (PWA)

تطبيق ويب مصمم خصيصًا لشاشات الجوال يساعدك على متابعة عداد الاستغفار، أذكار الصباح والمساء، أدعية مصنفة، مع تذكيرات مرنة ووضع نهاري/ليلي. تم بناؤه باستخدام **React** و **Tailwind CSS** مع دعم **PWA** للتثبيت على الشاشة الرئيسية والعمل دون اتصال.

## ✨ المزايا الرئيسية

- 📿 **عداد استغفار تفاعلي** بدائرة ذهبية تهتز عند الضغط مع تأثير بصري، ويحفظ التقدم اليومي تلقائيًا.
- 🌅 **وِرد الصباح والمساء** بخطوات متتابعة تظهر عدد التكرارات وتنتقل للذكر التالي حتى الاكتمال، مع حفظ الإنجاز اليومي.
- 📚 **مكتبة أدعية مصنفة** يمكن فتح كل قسم للاطلاع على الأدعية المتنوعة مع التكرار والمصدر.
- 🔔 **إعدادات تذكير مرنة**: أوقات الصباح والمساء، تذكير الاستغفار خلال اليوم، اختيار نغمة التذكير، وتفعيل/تعطيل الاهتزاز.
- 🌓 **وضع نهار/ليل متكامل** مع تصميم فلات متجاوب وعناصر عربية (RTL) سلسة.
- 📱 **دعم PWA كامل**: إمكانية الإضافة للشاشة الرئيسية، العمل بلا اتصال، وتحديثات تلقائية للخدمة.

## 📁 هيكلة المشروع

```
src/
├─ App.tsx                # التوجيه وتخطيط الواجهة الرئيسية
├─ components/TabBar.tsx  # شريط التبويب السفلي
├─ context/               # سياقات التفضيلات والتقدم
├─ data/                  # بيانات الأذكار والأدعية
├─ hooks/                 # خطافات للتخزين، الاهتزاز، التذكيرات، تقدم الأذكار
├─ pages/                 # صفحات الاستغفار، الصباح/المساء، الأدعية، الإعدادات
├─ utils/date.ts          # تنسيقات التاريخ الهجري/الميلادي
├─ index.css              # تهيئة Tailwind والأنماط العامة
└─ sw.ts                  # خدمة PWA مخصّصة (Workbox)
```

## 🚀 البدء محليًا

> تأكد من استخدام PowerShell (كما في بيئتك الحالية) وتشغيل الأوامر داخل مجلد المشروع.

```powershell
npm install
npm run dev
```

- يفتح الخادم على العنوان الافتراضي `http://localhost:5173/`.
- سيُطلب منك منح صلاحية الإشعارات عند تفعيلها من صفحة الإعدادات.
- للتثبيت كتطبيق، افتح قائمة المتصفح واختر «إضافة إلى الشاشة الرئيسية».

## 🛠️ أوامر إضافية

```powershell
# بناء نسخة الإنتاج
npm run build

# عرض نسخة الإنتاج محليًا
npm run preview

# فحص القواعد البرمجية
npm run lint
```

## 🔔 التذكيرات والإشعارات

- يتم جدولة التذكيرات عندما تكون الإشعارات مفعّلة (وتحصل على الإذن من المتصفح).
- اختيار «تذكير الاستغفار» يرسل إشعارًا دوريًا حسب الفاصل الزمني المحدد.
- الاهتزاز مفعّل فقط للأجهزة التي تدعمه.

## 🌗 تخصيص الوضع الليلي/النهاري

من صفحة الإعدادات يمكنك التبديل بين الوضعين. ينعكس الاختيار على عنصر `html` لتطبيق نمط Tailwind المناسبة، ويمكن حفظ التفضيل في `localStorage`.

## 📲 ملاحظات التثبيت (PWA)

- تم تفعيل `vite-plugin-pwa` مع تفعيل `autoUpdate` لتحديث الخدمة آليًا.
- يوجد ملف `manifest.webmanifest` وأيقونة SVG عالية الدقة.
- من الأجهزة الداعمة، سيظهر زر «التثبيت» داخل المتصفح (Chrome/Edge/Android).

## ⚠️ الأمن والتحديثات

بعد تثبيت الحزم ظهرت تنبيهات npm بثلاث ثغرات متوسطة في بعض التبعيات غير المباشرة. لا تؤثر على تشغيل المشروع، ويمكن متابعتها بأمر `npm audit` وتحديث الحزم لاحقًا عند توفر إصدارات أحدث.
